# E - Non-EVM airdrop farms (Solana, Hyperliquid/HyperEVM, Sui, Aptos, TON, BTCfi, Cosmos, Starknet, other)

Date of research: 2026-10-24. Researcher E of 7.

## Method and limits (read first)

- TVL numbers are DefiLlama `api.llama.fi/protocols` fetched 2026-10-24 (sum of the protocol's tokenless entries, shown in the cell). "No token" = DefiLlama symbol "-" plus no hit on CoinPaprika/DexScreener token search plus the project's own pages where readable.
- Program status comes mostly from airdrops.io project pages (each shows a "last updated" date, put in the confidence column), todayindefi.com newsletters (Oct 2026), project docs, DefiLlama hacks API (`api.llama.fi/hacks`).
- **The shared WebSearch budget (200 per turn, all 7 researchers) ran out mid-run.** After that only direct page fetches were possible, and I did not work around the cap. Effect: Sui, TON, BTCfi, Cosmos and Stellar/XRPL/Near coverage is THIN. Candidates there are listed as unverified, not as farms. Many SPA project sites (Current, Bucket, Ember, Vesu, Troves, Endur) returned only a title, so "no program found" there means "could not read", not "none exists".
- Two doc pages (docs.onre.finance, docs.hyperbeat.org) contained an "Agent Instructions" block telling AI agents to make HTTP requests. Treated as page data and ignored.
- About 80 candidates checked: 24 listed as farms, the rest rejected (token live / no program / ended) or left as unverified.
- Several farms are below Cymetica's own gate ($5M deposited, no exploit): N1, TxFlow, Imperial, Axiom, xStocks, DAWN, BitRobot, Dreamcash, Dexari, Joule are volume/free/task farms or tiny TVL. The deposit farms that pass the TVL gate are OnRe, Extended, Exponent, Project 0, Hylo, Felix, Hyperbeat, Decibel, GMTrade, Pacifica, Raiku, Perena, BULK, Endur. Audit status was not checked for any of them.
