# Segment A: perp / spot / options trading venues with a points or rewards program and no live token

Researched 2026-10-24. Compared against the 49 farms in `cym-farms.json`.

## How to read this

* **DL** = DefiLlama public API, fetched 2026-10-24: `api.llama.fi/protocols` (TVL, token `symbol` field) and `api.llama.fi/overview/open-interest` (OI, `total24h`). The perp *volume* endpoint is paid (HTTP 402), so **size = TVL and/or OI, not 30d volume**. TVL for off-chain engines is the bridge TVL (marked "bridge").
* **CG** = CoinGecko API `coins/markets` (used to prove a token is live and trading).
* **AIO** = the project's page on `airdrops.io/<slug>/` (dated, checked 2026-10-24). AIO statuses lag: it still lists Lighter and edgeX as "Confirmed / Join & Trade" although both tokens are live. Every AIO-only claim is marked `med` or `low`.
* **Docs** = the project's own documentation, read through its `llms.txt` index.
* **Limit hit:** the shared web-search budget ran out after 22 searches. The rest of the work is primary docs, DL, CG and AIO. No claim in the tables comes from a search snippet alone, except where it says "search".
* Confidence: `high` = project's own docs/ToS and DL agree. `med` = one primary or tracker source plus DL. `low` = tracker only, stale, or not cross-checked.
* "In Cymetica list?" is **no for every row**. None of the 49 farms is a trading venue except Fables and Fluxion Network. Chain overlap is noted where the list already holds the chain (Arc, Ink, Robinhood Chain, Tempo, Monad).
