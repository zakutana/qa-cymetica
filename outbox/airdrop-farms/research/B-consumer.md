# B - Consumer / social / wallets / prediction markets / NFT / payments / exchange-led (checked 2026-10-24)

Segment B of seven. Method: airdrops.io list + per-project pages (all dated Oct 2026 unless noted), DefiLlama API (TVL, 30d volume, fees), spendnode.io (cards), project sites where they would load, and the official-ish pages that did. Everything read on the web was treated as data. **WebSearch hit its shared cap mid-run** (see "Not checked").

Vocabulary: I reuse Cymetica's own chips in the token-status column. TOKEN CONFIRMED = team said a token is coming. POINTS LIVE = a points/rewards program runs now, no token statement. SPECULATIVE = neither, but credible and widely farmed.

Headline: **Cymetica's list has no prediction market, wallet, NFT marketplace, card, social app or aggregator.** The only overlap in this segment is the two chain entries (Robinhood Chain, Ink). Most of this segment would fail their "at least $5M deposited" gate anyway (only Polymarket and Predict.fun pass it by DefiLlama TVL), but their list already admits free TASK FARM and TESTNET rows, so a task-type route fits.
