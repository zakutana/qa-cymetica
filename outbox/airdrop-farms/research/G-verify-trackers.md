# G - verify Cymetica's 27 paid farms + tracker cross-check (2026-10-24)

## Method and limits (read first)

- WebSearch: the shared per-turn budget ran out after ~6 queries. Everything else is direct fetches: project sites and docs, airdrops.io project pages, DropsTab coin/activity pages, DefiLlama API (`/protocols`, `/hacks`), CoinGecko API, CoinMarketCap, DexScreener API. So some claims rest on one tracker page; marked "1 src".
- Blocked: CryptoRank (Cloudflare challenge, not bypassed), Earndrop (Cloudflare), DefiLlama /airdrops page (403 on fetch; the page is just the tokenless filter - I reproduced it from the API: 184 tokenless protocols with TVL >= $5M after dropping CEX/bridge/chain), CoinMarketCap airdrop page (empty JS), DropsTab per-coin pages 404 for many slugs. No "reputable outlet top-airdrops list" could be fetched (needed search).
- Chip rule I applied (their labels, my reading): TOKEN CONFIRMED = team has officially committed to a token; POINTS LIVE = an official points program is running; SPECULATIVE = neither.
- "Token live" means a native/governance token that trades. Receipt/product tokens (LsETH, USDX, USN, yUSD, dualCORE, spSEI, shMON, trUSD) do not count. shMON check: SHMON $0.0347 vs MON $0.0212 (CoinGecko, 24 Oct), same ATH date as MON -> LST receipt, not a governance token.
- Exploits: DefiLlama /hacks (1318 entries) matched by name AND by defillamaId against all 27 farms: no hits. Name collisions that are NOT these farms: Infini (2025-02, $49.5M, different company), NoOnes, INK Finance (2026-05, different from Ink chain), Robinhood (2023, exchange social-engineering). No second source checked for exploits.
- DefiLlama audit counts: every one of the 24 DeFi farms shows 2 audits (Fables 3), so "audited" is not what fails.
