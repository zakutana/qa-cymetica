# Build a Company, redesigned

A design proposal for Cymetica's Build a Company (https://cymetica.com/company), filed as a Build it Better request.

- `SPEC.md`: the brief, what to build and what is live today.
- `design/`: the working mockup of every screen. Open it at
  https://raw.githack.com/zakutana/qa-cymetica/main/outbox/company-spec/design/start.html, or serve `design/` locally
  (three.js loads from a CDN, so `file://` does not work).
- `screenshots/`: every screen at 2000 x 1100.
- `build-it-better/improvements.txt`: the request's text as filed.
